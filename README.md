Este proyecto consiste en el desarrollo de un sitio web con una estructura visual clara y una navegación sencilla. A continuación, se describen las decisiones de diseño y funcionamiento del sitio.
🏠 Estructura general del sitio
📌 Portada del sitio

La parte superior del sitio funciona como portada. Incluye:

    Una imagen de personas divirtiéndose.

    Tres botones ubicados en la esquina superior derecha.

    Una breve explicación sobre el propósito del sitio.

🐻 Separación visual con un oso

Justo debajo de la portada se ubica una imagen de un oso, que cumple una función meramente visual. Se utiliza como herramienta simbólica para separar claramente la portada de la siguiente sección: las actividades.
🗂️ Sección de actividades
🆕 Últimas actividades agregadas

Bajo el oso, se muestra un menú con distintas actividades recientes, cada una con su imagen representativa.
🔍 Visualización de detalles

En lugar de redirigir a otra página o abrir una ventana emergente, el detalle de cada actividad se encuentra oculto en la parte inferior del sitio.
Este contenido solo se despliega si el usuario hace clic en la imagen de una actividad o en el botón "Ver detalles".
🔄 Navegación dentro del sitio

Una vez desplegada la información de una actividad, se puede hacer scroll hacia abajo para leerla. En la esquina inferior izquierda se encuentran dos botones:

    "Volver al listado de actividades"

    "Volver a portada"

Estos permiten volver fácilmente a las secciones principales.
🛠️ Consideraciones de diseño

    La separación entre secciones es visual y lógica, no estructural en el código.

    Todo el contenido está en una misma página, pero organizado de forma clara para el usuario final.

    Esto cumple con los requerimientos de la tarea, al permitir distinguir cada parte del sitio de manera intuitiva.

➕ Agregar actividades

Al agregar una actividad, se despliega un formulario completo y funcional, que puedes mover libremente dentro de la página.

    Si algún campo no es válido para enviar el formulario, se muestra un mensaje de error en rojo justo sobre el botón "Submit", lo que deja muy claro qué falta por completar.

📈 Ver estadísticas

Al hacer clic en "Ver estadísticas", se redirige a otra página que muestra fotos de estadísticas relacionadas.

    En la esquina inferior izquierda de esa página hay un enlace que permite volver fácilmente al sitio web principal.
